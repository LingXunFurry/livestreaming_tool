# Fusion Pixel Font

字体作者为 TakWolf，本项目使用官方 2026.10.25 发行的 10px 简体中文比例版，文件原样保存，大小 415,688 字节。

[官方仓库](https://github.com/TakWolf/fusion-pixel-font)

[官方发行页](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25)

[下载包](https://github.com/TakWolf/fusion-pixel-font/releases/download/2026.10.25/fusion-pixel-font-10px-proportional-otf.woff2-v2026.10.25.zip)

`OFL.txt` 与 `LICENSES/` 为该发行包附带的版权及许可文件。字体及上游许可由 CP3 验收页提供链接，Vite 构建时随引用打包。官方 10px 字体包含 25,910 个字形。已使用同版 OTF 的字符映射表核对当前栏目和示例文案，均有字形。
