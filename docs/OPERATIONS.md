# 日常操作

## 初始化和启动

安装 Node.js 22.12 或更新受支持版本。首次在项目目录执行 `npm ci`。日常双击 `启动直播间.bat`，也可运行 `start.bat`。启动器自动定位目录、检查程序和配置、按需构建并等待健康检查。终端显示实际 URL 后再将地址加入直播客户端网页素材源。

首次启动由 `config/example.json` 建立 `data/settings.json`。默认地址为 `http://127.0.0.1:3000`。`/live/bilibili`、`/live/douyin` 和 `/admin` 分别对应两端直播源与基础后台。网页源尺寸设为 1920×1080。

## 停止与状态

双击 `关闭直播间.bat` 或 `stop.bat`，等待服务释放端口。通过 `检查运行状态.bat` 或 `status.bat` 查看实际版本、端口、启动时间、页面、WebSocket 和适配器状态。

开发调试使用 `npm run dev`，它是独立的 Vite 开发命令。日常使用统一入口。若旧开发预览占用端口，在其原启动窗口按 Ctrl+C 结束，或在设置中选择另一个端口。

## 修改和更新

调整端口或自动打开后台选项后正常停止，再启动。统一配置模块校验格式并备份写入。配置异常时参考错误提示和 `data/backups/` 中的设置备份。更新程序前先停止服务、备份设置与验收素材，再更新源码并执行 `npm ci`。

## 诊断

检查 `data/logs/runtime.log` 和轮换文件。运行 `npm run status -- --json` 获取机器可读信息。端口冲突时更改 `data/settings.json` 的 `server.port` 或正常关闭对应占用程序。服务异常退出后再次运行启动入口，由身份检查识别失效状态。

网易云桥接需要单独安装和启动，操作见 `MUSIC_SETUP.md`。酒馆启动器检查音乐适配器状态，但不启动或停止该桥接。外部适配器故障与核心网页服务分别报告；真实直播平台互动尚未接入。

## 备份与迁移

保留 `data/settings.json`、所需设置备份、规范和已确认资产。用户原图单独保管，凭证单独处理。按照 `MIGRATION.md` 在目标电脑初始化。日志有大小上限，自动轮换的旧日志与业务配置备份分开管理。
