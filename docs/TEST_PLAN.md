# 验证计划

每次报告列明实际运行的检查和结果。自动化覆盖可在当前环境重复执行的运行管理，直播客户端与第二台电脑保留实机验收。

## CP0

运行 `npm run build` 和 `npm test`。实际启动子进程检查健康、三路页面、运行状态、WebSocket 握手、双平台并发和关闭端口。测试重复与并发启动、被无关程序占用的端口、失效运行记录、非法配置、控制令牌保护、静态路径边界、日志轮换和配置原子备份。

在含中文与空格的新目录复制必要项目文件并从其他当前目录调用入口，检查迁移后相对路径工作。Windows `.bat` 入口需在当前 Windows 环境实际启动、查询、关闭。测试结果与源代码一起提交。

## CP1–CP5

CP1 构建后用真实服务和浏览器检查固定画布、游戏区及透明性、已确认区域坐标、歌词开关下右栏尺寸、两个平台布局差异和双路由并发，并保存几何数据与截图。CP2 检查三个独立 PNG 的真实透明通道、像素尺度、色板、光照及用户素材授权。CP3 检查资产清单、无 UI 背景和配置可重组性。CP4 检查模拟时间轴、事件合并和歌词开关。CP5 检查全局与平台配置隔离、保存恢复、双页同步及断线重连。

CP2 的离线命令 `pwsh -File scripts/prepare-cp2-assets.ps1` 检查三个 PNG 的 64×64 尺寸、透明留边、alpha 二值化与 V2 色板，并记录 SHA256。浏览器检查 `/assets/review` 的图像加载、整数放大、底色切换、下载字节一致性及窄窗口。两个直播源并发打开时复核画布、透明性和区域几何。造型、透视和质感以用户验收结果为准。

## CP3 场景检查

CP3 实际检查包括十二件模块的逻辑尺寸、alpha、十色色板和纹理对边接缝，背景全图逐像素检查，游戏窗口透明性，以及修改物件配方后的重组与原配方复现。非法窗口、未知资产、非整数比例、负坐标和越界图层应拒绝处理并保留已有背景。共享处理脚本默认 CP2 的三个 PNG 哈希须保持一致。

浏览器检查 `/scene/review` 的十二件素材显示、UI/平台/歌词/辅助线/底色切换、十三件 PNG 和布局下载文件和 375px 窄屏。两个正式源同时打开并复核四种平台与歌词组合的透明根层及 CP1 几何。保存截图和 `CP3_*_CHECKS.json` 记录。

## CP6–CP8

CP6 使用真实播放器验证暂停、切歌、进度、缺词与断连。CP7 使用授权事件验证弹幕、礼物、大航海、SC 和重连。CP8 覆盖直播姬、直播伴侣、透明显示、音画捕获、双路并发、长时间运行、异常恢复、备份恢复及新电脑迁移。

尚未实际执行的客户端兼容性和适配器测试统一记为待实机验收。

CP3 返修另行检查中英文组合艺术字、隐藏编号、面板内容完整性、本地字体与四份许可、吧台可见两端和右上陈设右端对齐、木框相邻 4,000 像素，以及图层 sourceRegion 的非法输入保护。
