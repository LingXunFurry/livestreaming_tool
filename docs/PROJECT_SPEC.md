## 最终目标

以凌巽的酒馆为主题，建立本地 Web 直播装修系统。首期固定 1920×1080 横屏，游戏内容保持画面主体。一个服务同时承载 B 站、抖音和统一后台。直播软件负责游戏、音频与编码推流，网页负责透明装饰层。OBS 是可选工具。

## 后续功能

B 站与抖音采用相同的酒馆背景、艺术字与留言板样式。每个平台通过自己的专属页面显示本平台弹幕，分别设置直播间地址，分别连接、保存设置和报告状态。B 站互动消息可包含弹幕、礼物、连续赠礼、大航海和 SC，抖音事件按实际适配器支持范围处理。网易云适配器提供经过实测的歌名、艺术家、播放状态、进度与同步歌词。歌词关闭后右侧主面板扩展。

评论不可用时，B 站自动将右栏切换为直播间公告；获得互动连接后按后台选择显示留言或公告。评论组件和公告组件在同一平台页面互斥显示；右栏显示公告时底部公告隐藏，右栏显示留言时底部公告显示。抖音固定使用右栏公告，不保留互动采集入口。公告内容可在后台设置，两平台正文分别保存。
