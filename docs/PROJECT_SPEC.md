# 产品规范

本规范落实 `V2_BRIEF.md`，CP0 已由用户验收通过，当前范围为 CP1 横屏布局线框。当前美术保持无背景灰度线框，已通过的区域位置与比例保留。

## 最终目标

以凌巽的酒馆为主题，建立本地 Web 直播装修系统。首期固定 1920×1080 横屏，游戏内容保持画面主体。一个服务同时承载 B 站、抖音和统一后台。直播软件负责游戏、音频与编码推流，网页负责透明装饰层。OBS 是可选工具。

## 页面

| 路由 | 职责 | 当前布局 |
| --- | --- | --- |
| `/live/bilibili` | B 站独立直播源 | 透明线框与明确标注的示例内容 |
| `/live/douyin` | 抖音独立直播源 | 任务公告线框与明确标注的示例内容 |
| `/admin` | 统一管理后台 | 只读系统状态和页面入口 |
| `/preview` | 布局预览 | 历史已确认布局，支持歌词开关的线框展示 |
| `/health` | 就绪检查 | 实际服务状态 JSON |
| `/api/runtime/status` | 组件状态 | 实际进程、页面、WebSocket 与适配器状态 |

两个直播页面可同时存在。全局信息和视觉复用，平台配置分别保存。平台专属数据故障隔离。后台完整编辑与广播属于 CP5。

## 后续功能

B 站提供统一互动消息流，纳入弹幕、礼物、连续赠礼、大航海和 SC。抖音首期提供公会任务、今日公告和目标卡。网易云适配器提供经过实测的歌名、艺术家、播放状态、进度与同步歌词。歌词关闭后右侧主面板扩展。

场景按后续检查点提供游戏直播、酒馆夜话、开播等待、暂时离席、酒馆打烊。统一后台最终支持双平台预览、场景切换、全局委托、平台独立设置、状态监控、设置保存和备份恢复。

## CP0 已完成范围

交付规范、统一启动/关闭/状态入口、配置模块、基础 HTTP/WebSocket 服务、日志、三个基础页面、健康检查和迁移设计。真实网易云、B 站事件、完整后台交互、正式美术与场景合成在对应检查点实现。竖屏、Windows 安装包及免安装运行环境属于后续可扩展内容。

直播姬与直播伴侣加载本地 URL、透明显示、音画捕获和双路编码效果在 CP8 实机验证。
