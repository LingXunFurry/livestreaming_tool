# 直播间美术规范

本文件是 CP2 及后续美术工作的执行依据。用户的新指示优先；未通过的草稿不得当作最终认可。

## 已确认方向

- 主题：西式奇幻冒险者酒馆。需要能辨认出木梁、吧台、酒桶、木杯、餐盘、食物及灯具，形成可信的室内空间。
- 媒介：真正的像素风素材与场景，轮廓有明确像素阶梯，像素密度统一。
- 不采用书斋、文人居所、茶室或森林主题；不以书法、纸张面板、书本和藤蔓作为主要视觉元素。
- 用户明确要求先做好背景，再处理艺术字。当前标题只作五字占位，美术未通过。

## 设定色板

颜色取自用户提供的完整设定稿顶部色板，而非道具、照片背景或助手自行选择的主题。

| 用途 | 颜色 | 色值 |
| --- | --- | --- |
| 主色 | 蓝灰 | `#6B85A5` |
| 深色结构、阴影 | 深蓝黑 | `#162333` |
| 明部、文字和陶器 | 白 | `#FFFFFF` |
| 次要蓝色 | 蓝 | `#5987CD` |
| 小面积重点 | 红 | `#B53932` |
| 红色阴影 | 暗红 | `#873230` |
| 少量灯光或高光 | 黄 | `#FFE479` |

- 整体以蓝灰、深蓝、白色为主。红、黄为点缀，不扩张为大面积底色。
- 禁止使用绿色作为本项目的装饰色或主题色，不添加绿色植物、绿色背景、绿色瓶罐和森林元素。
- 木材可使用少量中性灰棕作为辅助材质色，须融入设定配色，不让橙棕色覆盖整个画面。
- 单个素材尽量控制在 8–16 色；整组素材共用色板，避免每个模块单独产生大量相近颜色。

## 像素尺度

- 采用 16px 基础逻辑网格；素材可用 16×16、16×32、32×32、64×32 等整数倍尺寸。
- 显示时以 2×、4× 等整数倍放大，并使用最近邻显示（`image-rendering: pixelated`）。
- 一组素材保持一致的逻辑像素尺寸；小酒杯不能比桌子拥有更细碎的像素密度。
- 轮廓、明暗块面和材质均以有意设计的像素簇构成；不得用高精细插画加“像素化”滤镜冒充像素素材。
- 不使用平滑缩放、模糊阴影、摄影质感、高光泽立体字或连续绘画笔触作为像素主体。

## 模块化的含义

模块是可以独立定位、替换和重用的物件或结构件。例如：

| 模块 | 建议逻辑尺寸 | 用途 |
| --- | --- | --- |
| 酒杯/木杯 | 16×16 或 24×24 | 吧台、桌面陈设 |
| 酒桶 | 32×32 | 酒馆储酒区域 |
| 桌子/吧台段 | 64×32 或可重复拼接的瓦片 | 前景台面 |
| 木梁/支柱/墙面 | 16×16 可拼接瓦片或 16×64 构件 | 室内结构 |
| 壁灯/烛灯 | 16×32 | 室内灯光来源 |
| 餐盘/面包/食物 | 16×16 或 32×16 | 表现酒馆生活感 |

- 可使用带透明通道的独立 PNG，也可使用布局明确的像素图集（atlas）及对应的坐标清单。
- 图集中的每个模块必须是真正独立的物件/瓦片，坐标、尺寸和放大倍数有记录。
- 在代码中组合物件与结构件来构建酒馆。不得把一张完整场景插画裁成上下左右几个矩形，声称这些就是素材模块。
- 背景结构、家具与陈设、标题、功能面板应能分别更改。

## 素材来源与生成

- 优先寻找有清楚授权的像素素材，如 CC0 或明确允许项目使用/修改的素材包。
- 从作者或发布平台的原始页面核实许可，并保存来源链接、许可文本、作者、实际使用的文件或图块坐标。
- 不把“网上能看到”“免费下载”当作可复用许可。需要署名的素材须保留署名要求。
- 不明确许可的作品只作视觉参考，不拷入项目作为素材。
- 使用生图时逐个物件或按独立素材图集生成，明确指定逻辑像素尺寸、透明背景、统一色板和像素边缘；生成后人工检查风格与可拆分性。
- 生图结果须保存到本地项目中，记录最终提示词及生成方式。未通过的整幅环境插画不接入项目。

## 参考作品的边界

- 用户完整设定稿用于抽取色板与整体气质；不照搬角色形象、姿势、服装图案、身体标记或特定标志。
- 用户提供的酒馆像素稿用于理解空间、材质与生活气氛；不复刻其人物、构图、家具位置或具体画面。
- 使用自己的环境布置和物件组合。保存许可记录与来源，不承诺未经核验的版权结论。
- 不把用户提供的角色参考原图复制进公开资源目录或仓库。

## 布局与验收

- 沿用 CP1 已通过的 1920×1080 布局。游戏区域为 X=40、Y=144、1280×720，真实源内必须完全透明。
- 右栏、歌词开/关后的尺寸及今日委托位置按 `PROJECT_SPEC.md` 执行，装饰不得遮挡游戏或降低文字可读性。
- 两个平台共用相同视觉规范，专属内容分别显示。
- 当前先交付背景与模块素材清单、真实可打开的组合预览及关键截图；标题暂不视为最终美术。
- CP2 美术须单独验收。布局通过不代表美术通过，背景草稿通过也不代表标题或后续阶段通过。
