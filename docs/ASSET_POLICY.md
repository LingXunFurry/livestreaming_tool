# 美术素材政策

用户的角色稿件、兽装照片和角色像素图默认保持原样并留在用户掌握的位置。使用、修改、AI 重绘、图生图、裁切、抠图、局部补全、改色、外观修改、衍生角色和融入新场景均需用户明确授权。后续获准展示的原图按授权范围完整、等比例展示。

## 模块制作流程

先确认布局和清单，再逐件制作真正透明的 PNG，检查像素质量与色板，交由用户验收，最后离线组合背景并叠加网页功能组件。每件素材有独立文件和明确用途。生图按物件执行，保持统一像素密度、描边、光照、透视和色板。

CP2 本轮之后仅制作酒杯、木桌和蜡烛三个原创透明素材，以独立展示板验收。获得确认后才能扩大素材数量。其他物件可包含酒瓶、书架、柜台、提灯、魔法书、公会任务板和风元素装饰，按 CP3 的清单制作。

完整场景一键生图和将整幅插画切成区域的方式不符合模块制作规范。复杂 CSS、SVG 路径或 Canvas 场景绘图同样不作为主体美术。CSS 用于布局、文本、简单边框和基础交互，SVG 可用于功能图标。

## 文件与清单

`assets/manifest.json` 登记名称、独立路径、来源、生成方式、提示词文件、版本、逻辑尺寸、用途、许可和用户确认状态。目录分为 `generated`、`backgrounds`、`ui` 和 `user-originals`。用户原稿目录默认忽略 Git，当前运行资源中没有用户角色原图。

CP0 清单为空且明确标注当前阶段。生成源文件和验收结果分开保存。无 UI 背景与含 UI 的预览在 CP3 分别提供，可调整的物件布局配置随之交付。

## 质量与来源

PNG 必须具有实际透明通道，检查边缘残留与伪棋盘背景。质量不符时修改或暂缓采用。开源或第三方素材先核对作者原始页面的许可，再保留原文、署名与文件清单。免费可见和允许复用分开核实，来源不明的作品仅供观察。

此前已提供的参考图仅作为需求背景记录。V2 生效后，新增 AI 输入按本文件重新核对授权范围。既有美术草稿保存为本地备份，活动页面恢复灰度线框。
