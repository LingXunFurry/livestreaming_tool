# 本地运行架构

最终使用 `server/collector.mjs` 管理 B 站采集器的本机控制连接 `/ws/ui` 和数据连接 `/ws/data`。后台可设置数据地址、exe 路径及自动启动。首次一键操作会在接口不可用时尝试启动已配置采集程序，连接后将事件送入统一接收链路。停止时关闭自己的数据连接，并核对房间后停止自己控制的采集任务。自动启动默认关闭。抖音固定公告。本轮最终验证使用本机模拟接口，真实采集已经停止。

最近 100 条事件按平台原子保存到 `data/messages/<platform>.json`。桌面应用对应 `%APPDATA%/LingxunTavern/messages/`。关闭服务前等待写入，重启后恢复消息和带 ID 事件的去重信息，网络接收状态仍由当前连接与新数据计算。

2026-11-13 实测采集器主动转发采用每条消息新建并关闭连接。有效事件或房间统计到达后保留 15 秒接收状态，配合采集器 3 秒房间信息推送避免留言板反复退回公告。连接数与最近数据时间独立记录，超过宽限期且无连接时回退公告。

2026-11-11 追加 Live Stream Sniffer Pro 本机主动推送。默认端口下抖音目标为 `ws://127.0.0.1:3000/ws/ingest/douyin`，B 站目标为 `ws://127.0.0.1:3000/ws/ingest/bilibili`。后台开启对应平台接入后可连接，采集器断开时右栏恢复公告。连接数、事件数、最近事件时间和房间统计分别报告。外部采集程序保存在 `.cache/live-stream-sniffer/`，由用户启动。

2026-11-08 用户授权追加 Windows x64 免安装桌面应用。采用 Electron 包装现有本地后台与预览，通过现有统一入口管理服务。应用包含运行所需 Node/Chromium 和本机网易云桥接运行环境，普通配置保存在用户目录，进程状态继续单独管理。窗口关闭时提供保留服务或退出并停止的明确选择。封装先交付本机验收。

Node.js 最低版本 22.12。首次初始化运行 `npm ci`，之后通过 `启动直播间.bat` 或 `start.bat` 启动。脚本定位自身目录，检查 Node.js，调用统一运行管理入口。前端由 Vite 构建，运行期间只需要一个 Node.js 服务。

## 生命周期

CP6 追加：音乐设置启用且地址为默认本机桥接时，启动入口尝试启动项目内已安装的 Python 桥接。已有监听不覆盖、不停止；缺少依赖或端口冲突时保留基础服务并提示。进程生命周期及身份必须可核实。

启动器读取项目身份与本地运行记录，复用同一实例。启动锁覆盖配置初始化、构建和服务就绪过程。新实例检查依赖、程序文件、配置与端口，创建后台进程并等待 `/health` 与实例身份匹配，随后打印实际端口的三个页面 URL。

服务采用独立后台进程，Windows 子进程窗口隐藏，启动命令窗口关闭后服务继续运行。`server.openAdminOnStart` 控制是否打开后台，默认关闭。项目默认没有开机自启动，重启电脑后再次运行启动入口。

停止入口通过本地运行记录和随机控制令牌请求当前项目服务正常关闭。服务关闭 WebSocket、内部心跳和 HTTP，清理自己的运行记录。停止入口不按进程名称批量结束程序。原来的开发预览属于独立开发命令，管理器检测到其端口占用时报告冲突。

## 状态与端口

默认 `127.0.0.1:3000`。端口在 `data/settings.json` 配置，诊断测试也可使用 `TAVERN_PORT`。主机限定为 `127.0.0.1`。端口被其他程序占用时显示尝试端口及处理办法，由用户更改配置或关闭对应程序。

`RUNNING` 表示服务与基础页面可用。`STOPPED` 表示当前项目实例未运行。`DEGRADED` 表示基础服务运行但已启用的可选适配器不可用。`ERROR` 表示配置、文件、端口或实例状态异常。未启用的适配器状态单独显示，不影响基础服务就绪。

`/health` 返回就绪和实例标识。`/api/runtime/status` 返回版本、启动时间、实际端口、页面、WebSocket 和适配器状态。公开接口省略控制令牌、凭证、Cookie 和本机绝对路径。

CP7 不再暴露抖音外部采集器端点，避免将 Dycast 的 403 或连接失败状态当作项目互动状态。B 站已配置房间但未获官方授权时为 `WAITING_AUTHORIZATION`，页面使用公告回退；抖音不显示互动适配器状态。

CP5 的 `/api/settings` 只读写普通可编辑配置，不包含进程状态或敏感凭证。写入限制在本机同源请求，服务端校验字段与长度后备份旧文件并原子替换设置文件；成功后通过 WebSocket 广播。平台设置事件携带平台标识，只更新对应直播页面。

## 日志和恢复

CP6 后端每 500ms 串行采样本地音乐桥接，单次请求有超时和响应体上限。音乐配置关闭时为 `DISCONNECTED`，连接中为 `CONNECTING`，可用为 `CONNECTED`，已启用但不可达或协议错误时为 `UNAVAILABLE`。客户端未启动和无歌曲为独立播放状态。停止酒馆服务时关闭自身轮询，用户自行运行的桥接进程由用户管理。外部桥接安装在本地独立目录，其安装路径、Python 环境和内存偏移属于本机依赖，迁移后重新验证。此次研究用源码放在忽略的缓存目录，来源及客户端版本写入 CP6 验收记录。

结构化日志位于 `data/logs/runtime.log`，达到 1MiB 后轮换，保留三个历史文件。记录启动、停止、关键错误、WebSocket 连接事件和适配器状态。日志过滤凭证类字段。

异常退出后再次运行启动入口，健康与身份检查会识别失效记录。死进程留下的启动锁可自动清理，存活进程所属的锁保留。当前采用明确重新启动的恢复方式，自动守护与长期恢复压力测试在 CP8 验收。

缺少网易云桥接器或 B 站授权时显示未连接或未配置，基础服务仍可正常运行。
