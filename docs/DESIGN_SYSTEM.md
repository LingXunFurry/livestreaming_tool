# 视觉设计系统

主题为凌巽的酒馆、冒险者公会和复古像素 RPG，强调温暖的幻想酒馆与克制的风元素。游戏画面占主体，界面具有精心设计的独立像素游戏质感。

## 固定 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| `navy` | `#1E2B45` | 主背景 |
| `night` | `#142238` | 深背景、阴影 |
| `mist` | `#7083A0` | 边框 |
| `slate` | `#364E6A` | 次级面板 |

V2 的固定 Token 替代此前从图片抽样得到的临时色板。深蓝与中性色占主导，金、红、风蓝小面积使用。绿色主题已被用户否定。修改主题 Token 需要用户确认。

## 像素和文字

像素素材采用 16px 基础逻辑网格，物件可用 16×16、32×32、64×32 等整数倍。整组素材统一轮廓、像素密度、视角和光照，显示时使用整数倍最近邻放大。CP3 场景验收预览中的栏目与 UI 文案统一使用本地打包的 Fusion Pixel Font 10px 比例版；字体按 OFL-1.1 附带许可证。标题“凌巽的酒馆”使用独立生成的透明艺术字图，不依赖系统字体。以上风格只作用于 CP3 场景预览，不改变已通过的直播源布局。

## 窗口和布局

用户最新确认 B 站和抖音采用同一套酒馆外观与留言板样式。平台专属链接、房间设置和消息内容分别独立。抖音留言板采用已制作的 COMMENT 组合艺术字与同一正文排版，事件类型文字按平台区分。

CP2 制作采用 64×64 逻辑画布。生成源稿单独保留，交付 PNG 通过最近邻采样统一像素网格，RGB 就近映射到上表十个 Token，alpha 归一为 0 或 255。展示板用 1× 原尺寸和 4× 最近邻放大展示，每件占独立窗口，并提供深蓝、奶油白与棋盘底色检查边缘。此处理落实 V2 的像素尺度与色彩统一流程。

窗口使用简洁 RPG 菜单结构和清楚边缘。区域坐标依照 `PROJECT_SPEC.md` 的已确认布局。游戏保持 16∶9，不拉伸。顶部和委托栏轻量化，右侧承载信息。界面边框和文字可用 CSS，家具和场景主体使用验收过的独立美术资产。

## 装饰控制

CP3 的木墙/地板为 64×64，木梁为 128×32，挂灯为 32×64，酒瓶架为 128×64，酒桶为 64×64。交付图使用最近邻采样、十色映射与二值 alpha。木墙额外把深木棕映射为深海军蓝、浅木棕映射为石板蓝，以满足深蓝主调。纹理的最后一行和一列复制对边像素以统一平铺边界。源稿完整保留。

CP2 的酒杯、木桌、蜡烛三个原创透明素材已通过。CP3 可使用融合式透明场景组表达相互关联的酒馆结构与陈设，并继续以离线配方组合；不把完整 1920×1080 场景一次生成，也不把杯、烛、桶等小物孤立陈列。家具和装饰不得遮挡游戏区或已确认 UI。角色展示留待单独授权。

CP3 场景底色以夜幕蓝、深海军蓝和木棕为主，暖金仅用于少量灯光像素，不引入绿色主题。游戏区仍为 1280×720 真透明窗口；场景在该矩形内不得残留图像像素。场景预览单独叠加现有 CP1 UI，正式直播源保持不变并等待场景验收。

CP3 预览以作用域 CSS 将已有 UI 呈现为符合固定色板的复古 RPG 面板，并让栏目文案使用本地简中像素字体。标题区保持透明背景，叠加独立制作的五字艺术字图。场景的细节层次应围绕清楚的酒馆视觉焦点组织，避免重复纹理与孤立物件形成道具陈列感。位置与美术仍等待本阶段验收。

## 风格检查

CP3 追加调整要求左右上角使用不同的酒馆陈设。底部柜台沿游戏区左右边线布置。评论区的“酒馆留言板”单独生成更醒目的像素艺术字，作为评论区标题叠加，沿用固定色板、透明底和统一的像素边缘。

木框布局裁去素材透明留边，游戏窗口四边紧贴实际不透明木梁。吧台可延长中间木面，使左右可见端点与游戏窗口一致。

右上陈设放大至约 500px 可见宽度并右对齐留言板。留言板标题区隐藏原“02 / 留言”编号，组合艺术字上移，保留标题、说明、评论与底部分类的清楚层次。

评论区与播放区采用中英文组合艺术字，英文 `COMMENT`、`NOW PLAYING` 较小，以少量遮挡形成主副标题的前后关系，两者共同生成为透明图像。

检查像素边缘、透视、比例、色板、文字层级和留白。拒收厚涂、写实光照、模糊材质、华丽浮雕金边、过量粒子、连续光晕、无意义渐变和过圆的现代卡片。CP1 使用无背景灰度线框检查结构，正式颜色和素材在 CP2 验收。
