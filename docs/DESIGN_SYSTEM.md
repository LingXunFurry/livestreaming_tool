# 视觉设计系统

主题为凌巽的酒馆、冒险者公会和复古像素 RPG，强调温暖的幻想酒馆与克制的风元素。游戏画面占主体，界面具有精心设计的独立像素游戏质感。

## 固定 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| `navy` | `#1E2B45` | 主背景 |
| `night` | `#142238` | 深背景、阴影 |
| `mist` | `#7083A0` | 边框 |
| `slate` | `#364E6A` | 次级面板 |
| `cream` | `#F3ECDD` | 主要文字 |
| `gold` | `#C9A85E` | 标题和强调 |
| `red` | `#D24943` | LIVE、警示 |
| `wind` | `#A8C7D1` | 风元素 |
| `woodDark` | `#5A3E2B` | 木质结构 |
| `woodLight` | `#8A6547` | 木质高光 |

V2 的固定 Token 替代此前从图片抽样得到的临时色板。深蓝与中性色占主导，金、红、风蓝小面积使用。绿色主题已被用户否定。修改主题 Token 需要用户确认。

## 像素和文字

像素素材采用 16px 基础逻辑网格，物件可用 16×16、32×32、64×32 等整数倍。整组素材统一轮廓、像素密度、视角和光照，显示时使用整数倍最近邻放大。正文优先清晰可读的本机中文字体。标题最终为独立制作的五字艺术字，在素材阶段单独验收。

## 窗口和布局

CP2 制作采用 64×64 逻辑画布。生成源稿单独保留，交付 PNG 通过最近邻采样统一像素网格，RGB 就近映射到上表十个 Token，alpha 归一为 0 或 255。展示板用 1× 原尺寸和 4× 最近邻放大展示，每件占独立窗口，并提供深蓝、奶油白与棋盘底色检查边缘。此处理落实 V2 的像素尺度与色彩统一流程。

窗口使用简洁 RPG 菜单结构和清楚边缘。区域坐标依照 `PROJECT_SPEC.md` 的已确认布局。游戏保持 16∶9，不拉伸。顶部和委托栏轻量化，右侧承载信息。界面边框和文字可用 CSS，家具和场景主体使用验收过的独立美术资产。

## 装饰控制

CP3 的木墙/地板为 64×64，木梁为 128×32，挂灯为 32×64，酒瓶架为 128×64，酒桶为 64×64。交付图使用最近邻采样、十色映射与二值 alpha。木墙额外把深木棕映射为深海军蓝、浅木棕映射为石板蓝，以满足深蓝主调。纹理的最后一行和一列复制对边像素以统一平铺边界。源稿完整保留。

CP2 的酒杯、木桌、蜡烛三个原创透明素材已通过。CP3 只增加强化酒馆辨识所需的木墙/地板纹理、木梁、挂灯、酒瓶架与酒桶，并在离线流程中组合；家具和装饰不得遮挡游戏区或已确认 UI。角色展示留待单独授权。

CP3 场景底色以夜幕蓝、深海军蓝和木棕为主，暖金仅用于少量灯光像素，不引入绿色主题。游戏区仍为 1280×720 真透明窗口；场景在该矩形内不得残留图像像素。场景预览单独叠加现有 CP1 UI，正式直播源保持不变并等待场景验收。

CP3 预览用作用域 CSS 将已有 UI 显示为深蓝 RPG 面板，标题区使用透明底与金色系统楷体。楷体是本次整体预览的临时字体选择，正式五字艺术字仍须独立制作和验收。物件位置属于本阶段待验收的场景方案。

## 风格检查

检查像素边缘、透视、比例、色板、文字层级和留白。拒收厚涂、写实光照、模糊材质、华丽浮雕金边、过量粒子、连续光晕、无意义渐变和过圆的现代卡片。CP1 使用无背景灰度线框检查结构，正式颜色和素材在 CP2 验收。
