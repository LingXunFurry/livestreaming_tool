## 当前限制

本机采集器会重复推送已有弹幕，当前输出缺少源消息 ID。最终版本对无 ID 的普通事件按平台、用户、类型和内容进行 60 秒滑动窗口去重，重复到达延续窗口，历史重复记录在恢复时合并。带 ID 的事件精准去重。无 ID 的礼物、大航海与 SC 按独立事件保留，以支持连续赠送。该取舍会合并同一用户在窗口内真实发送的相同普通弹幕，采集器补充源消息 ID 后可进一步精确处理。真实数据中的单条“[比心][比心][比心]”重复样本已加入回归检查，部署时已合并 83 条历史重复记录。实际大航海与 SC 继续等待用户检查。用户要求本轮优先完成消息显示，采集软件界面重连行为由该软件管理。
