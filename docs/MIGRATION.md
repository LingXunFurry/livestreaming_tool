# 跨电脑迁移

## 开发版

复制仓库源码、锁文件、规范、已验收素材以及需要保留的 `data/settings.json` 和配置备份。目标电脑安装 Node.js 22.12 或更新受支持版本，在项目目录执行 `npm ci`。随后运行 `启动直播间.bat`，由入口按需构建前端并启动服务。

项目可以放在不同盘符、含中文或空格的路径。脚本以自身目录定位项目，Node.js 模块以文件位置定位资源。端口、普通设置和可选外部路径由配置模块管理。

## 保留与重新生成

保留普通设置、平台设置、委托与公告模板、布局、美术素材清单和确认记录。日志与历史备份按需要带走。敏感凭证单独安全迁移，目标电脑重新检查授权及外部依赖。

`node_modules/`、`dist/`、`.cache/` 和 `data/runtime/` 可在目标环境重新建立。旧 PID、实例令牌、启动锁、绝对路径和端口占用记录属于本机临时状态。复制前在旧电脑通过关闭入口停止服务。

## 便携发行版

后续将构建产物、独立素材、配置示例与受支持的运行环境一起打包。首期交付开发版，初始化需要 Node.js 和依赖安装。Windows 安装程序及真正免安装发行版尚未实现。

## 验收

CP0 先在新的含中文与空格目录中模拟迁移，测试端口配置、统一入口、页面、状态、关闭与配置读取。CP8 再在目标直播电脑检查真实素材、完整设置保存、备份恢复、平台依赖和客户端。单机目录复制测试的结论仅覆盖当前电脑。
